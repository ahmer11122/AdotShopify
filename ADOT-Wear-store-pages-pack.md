# ADOT Wear: Store Pages

Canonical store copy for FAQ, Shipping, Exchange, About, Terms, and Privacy.

Brand text uses **ADOT Wear**. Links, email, and handles keep `adotoffical` / `adotofficial`.

See also `launch-copy/` for policy HTML, and theme files:

- `templates/page.faq.json`
- `sections/shipping-policy-page.liquid`
- Admin policies via `shopPolicyUpdate`
- About page Admin id `gid://shopify/Page/165939478706`

## Key numbers

| Item | Value |
|---|---|
| Free shipping | Rs. 6,000 and above |
| Paid shipping | Rs. 250 under Rs. 6,000 |
| Processing | within 24 hours |
| Delivery | 3 to 4 working days, Mon–Fri |
| Support hours | Mon–Sat, 10:00 AM to 12:00 AM (PKT) |
| Exchange window | 7 days |
| Faulty claim | 48 hours + photos + unboxing video |
| Refunds | Not offered |

## Owner follow-ups

1. Privacy policy: turn off automatic management in Admin (or grant `write_privacy_settings`), then paste `launch-copy/privacy-policy.html`.
2. COD: enable in Settings → Payments if not already on.
3. Store display name: set to **ADOT Wear** in Settings → Store details if desired (Admin API rename returns 406).
